# 太平洋の翼 〜敵の港を撃破せよ！〜

小学4年生が設計した、太平洋戦争をテーマにした3D海戦ゲームです。
戦闘機・軍艦・潜水艦から乗り物をえらんで出撃し、敵の港の撃破を目指します。

**▶ 遊ぶ: https://abolabo84-dev.github.io/pacific-wings/**

- スマートフォン・タブレット・パソコンのブラウザで動きます（アプリのインストール不要）
- 1ファイル完結。外部サーバーへの通信は一切ありません

## 操作

| | パソコン | スマホ・タブレット |
|---|---|---|
| 操縦 | ↑↓←→ キー | 画面左をなぞる |
| メイン攻撃 | スペースキー | 🔥ボタン |
| サブ攻撃（爆弾・魚雷・爆雷・発艦） | B キー | 💣ボタン |

## 遊びかた

- 敵の港を撃破すれば勝ち。味方の港を撃破されたら負け
- 敵を5つ撃破すると切り札が、10撃破すると2隻目が出撃
- 乗り物には相性があり、対潜水艦機は潜水艦に、対空母機は空母に大ダメージ
- 戦闘機は燃料が切れる前に、味方の島か港の上を低く飛んで補給
- ゲーム内20分ごとに霧が発生し、5分間レーダーが使えなくなる
- 現実時間5分ごとに、敵の増援（飛行機・船・潜水艦が1つずつ）が出現
